Este proyecto es un currículum vitae online desarrollado en HTML5 y CSS3, pensado como una presentación personal y profesional. Incluye secciones de información básica, educación, experiencia laboral, habilidades y proyectos, con un diseño minimalista y adaptable. El proyecto utiliza Flexbox para organizar los contenidos en columnas y filas, un header con navegación interna, y un footer con enlaces de contacto. Además, se aplicó una paleta de colores suaves y tipografía Poppins para dar coherencia visual. Mi pantalla tiene una resolución de 1366x768.
